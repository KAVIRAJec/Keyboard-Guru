# Keyboard Guru

Personal keyboard shortcut reference repo for Kaviraj.

## Structure

```
Keyboard-guru/
├── general/          # OS-level and universal shortcuts
├── vs-code/          # VS Code editor shortcuts
└── powerlevel10k-git/ # Powerlevel10k theme + Git CLI shortcuts
```

## Conventions

- Each folder contains one or more `.md` files grouping related shortcuts.
- Format for each shortcut entry:
  ```
  | Shortcut | Action |
  ```
- Add a short description at the top of each file explaining the context.
