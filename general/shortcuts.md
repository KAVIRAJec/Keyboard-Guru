# General Shortcuts

Universal shortcuts across macOS / system-level.

| Shortcut | Action |
|----------|--------|
| ⌘ + ` | Switch between open windows of the same (currently active) app |
| ⌘ + Shift + ` | Switch between windows of the same app, in reverse order |
| ⌃ + ↓ (or 3/4-finger swipe down on trackpad) | Show all open windows of the current app (App Exposé) |
