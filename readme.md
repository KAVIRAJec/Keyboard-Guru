# Keyboard Guru

Personal keyboard shortcut reference — a single place to look up shortcuts across tools and environments.

## Structure

| Folder | Contents |
|--------|----------|
| [`general/`](general/shortcuts.md) | macOS / universal shortcuts |
| [`vs-code/`](vs-code/shortcuts.md) | Visual Studio Code shortcuts |
| [`powerlevel10k-git/`](powerlevel10k-git/shortcuts.md) | Oh My Zsh git aliases + Powerlevel10k |
| [`arc-browser/`](arc-browser/shortcuts.md) | Arc browser shortcuts |
| [`microsoft-teams/`](microsoft-teams/shortcuts.md) | Microsoft Teams shortcuts |

## Usage

Browse the folder for the tool you need, or search for a shortcut with `Cmd + F`.
